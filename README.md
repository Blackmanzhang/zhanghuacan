# 海上有信

面向两岸及海外华人青年的本地数字书信网页。使用 Python 3.10 及以上版本和 SQLite，无需安装第三方依赖。

## 打开项目

在 Windows 上双击「启动项目.cmd」。它会启动书信服务并打开浏览器。已经运行时会打开现有网页。通过终端启动也可以执行以下命令。

```powershell
python server.py --open
```

本机访问地址为 http://127.0.0.1:8765/ 。服务默认只监听本机，关闭运行服务的终端即可停止。书信、账号、授权及附件保存在 data/letters.sqlite3，草稿保存在当前浏览器中。需要长期保留访客书信时，请到「我的海」选择「保存为账号」。

## 体验故事

完整示例库含 64 封书信、26 个公开地域和 40 次跨地接力。作者与故事均为原创虚构示例。进入「拾信广场」查找来信，或从「故事回响」查看分支。用两个不同的浏览器配置或一个普通窗口与一个隐私窗口，可以模拟两个独立参与者。示例作者用于展示，真实的私信往来请使用两个自己的测试身份。

作者寄出的新信会显示在「我的海」。公开来信和公开接力须经本机管理员审核。通过后刷新网页即可在拾信、故事树与时间线中看到更新。私密回信直接存入双方的私人信箱。作者可分别设置接力与展览授权，也可撤回整封信。

## 海上手账

打开「海上手账」选择主题手账，按目录翻阅，或点击「我也写一页」。完整示例包含七本主题手账、三十一页原创示例，其中部分页面附有手绘和带出处的词音。投稿可组合文字、照片、录音和手绘。已有页面可以继续回应并引用一句原文。草稿存入当前账号或访客身份，审核通过后才加入公开目录。

投稿时点击「打开专业画板」。滚轮缩放，按住空格或切换到抓手后拖动画布，点「查看全图」回到作品范围。插入手账后保存草稿，之后可以继续编辑原笔触与图层。手账中的画作可以全屏查看、平移、缩放和导出 PNG。经作者授权的公开画作可作为一页续作的底图，撤回或关闭授权后其他页面停止展示该底图。

手账正文也支持 DeepSeek 草稿。填写标题，按需填写公开地区和文化标签，再点击「AI 生成正文」。预览后选择使用，正文仍可自己修改。

## 书信与文化探索

首页的书信地球按公开地域显示信封，金色航线表示跨地域的公开接力。拖动或按方向键旋转地球，点选信封可拆信或浏览同一地点的其他来信。地点选择框也能定位到球体背面的区域。陆地点阵来自公有领域的 Natural Earth 1:110m。首页的四个文化空间分别通往乡音展馆、海上手账、文化地图和知识图谱。

1. 打开「文化地图」，可从泉州、澳门、开平、越南顺化、泰国大城等 16 个地点进入 32 张文化卡，查看资料来源和相关来信。
2. 阅读开放接力的书信。选中一句原文并点击「公开接力」，或在编辑时从原信中选句。写信或接力时，可从 10 张内置封面中选一张，也可上传自己的 JPG、PNG 或 WebP 图片（最大 8 MB，由浏览器压缩）。可再附一张正文图片或一段录音，并从 7 种信纸与 7 枚邮票中搭配。点击「预览信笺」查看组合，点击「保存草稿」可在同一浏览器恢复封面和样式。

乡音展馆收录 107 段附出处与许可的原声，可对听台语、粤语和四县客语。知识图谱收录 47 个文化词条和 49 条关系，可旋转球体查看沿球面绘制的关系弧线，或从地图进入对应词条与乡音档案。

### 高德地图

文化地图使用高德地图 JS API 2.0。在高德开放平台获取 Web 端（JS API）的 Key 和安全密钥，在服务端的 `data/amap.local.json` 中写入 `{"key":"Web 端 Key","securityCode":"安全密钥"}`。浏览器会使用 Key 加载地图，安全密钥由服务端代理添加。Git 忽略此配置文件。在高德开放平台的域名白名单填写实际访问域名。本地预览使用 `127.0.0.1`。底图加载失败时，可用「列表」继续浏览文化地点。

### AI 写信

写信或公开接力时，先填写标题、主题、公开地域和文化标签。点击「AI 生成正文」后，可预览草稿，再选择使用并继续编辑。点击生成只会把这四项发送给所配置的模型服务。已写的正文、引用及附件由站点保留在当前表单中。

在本机使用 DeepSeek 时，将 API Key 单独保存在服务端的 `data/deepseek.local.key` 文件中，刷新写信页即可使用 `deepseek-flash`。该文件由 Git 忽略。专用的 `SEA_DRAFT_MODEL_*` 环境变量优先于本地配置。

| 变量 | 含义 |
| --- | --- |
| `SEA_DRAFT_MODEL_URL` | 完整的 Chat Completions 兼容端点。远端使用 HTTPS，本机回环地址可用 HTTP。 |
| `SEA_DRAFT_MODEL_NAME` | 服务所用的模型名称。 |
| `SEA_DRAFT_MODEL_KEY` | 服务端密钥。本地模型不要求认证时可留空。 |

专用环境变量和本地 DeepSeek 配置均未设置时，AI 写信使用已有的 `SEA_TAG_MODEL_*` 配置。也可通过环境变量临时指定 DeepSeek。先关闭当前运行的本机书信服务，再在项目目录的 PowerShell 中运行下面的命令。终端会遮盖 API Key 输入。

```powershell
$env:SEA_DRAFT_MODEL_URL = 'https://api.deepseek.com/chat/completions'
$env:SEA_DRAFT_MODEL_NAME = 'deepseek-flash'
$env:SEA_DRAFT_MODEL_KEY = [System.Net.NetworkCredential]::new('', (Read-Host '输入 DeepSeek API Key' -AsSecureString)).Password
try {
    .\启动项目.cmd
} finally {
    Remove-Item Env:SEA_DRAFT_MODEL_KEY -ErrorAction SilentlyContinue
}
```

启动后进入「写信」即可使用。密钥通过服务器环境变量提供。网站默认监听本机地址。

### 文化标签

默认使用本机词表。点击「识别文化元素」取得候选，点击候选后才加入书信。也可直接输入标签。若要使用模型，站点管理员可以在启动服务前设置这些环境变量。

| 变量 | 含义 |
| --- | --- |
| `SEA_TAG_MODEL_URL` | 完整的 Chat Completions 兼容端点。远端使用 HTTPS，本机回环服务可使用 HTTP。 |
| `SEA_TAG_MODEL_NAME` | 服务所用模型名称。 |
| `SEA_TAG_MODEL_KEY` | 服务要求认证时使用的密钥，保留在服务端。 |

只有作者为本次识别单独勾选授权后，服务才向所配置端点提交标题和正文。界面注明候选来自模型或本地词表。端点未配置或不可用时，仍可手动选词、写信和共创。

## 管理审核

可从网页页脚打开「内容审核」。先在本机项目目录执行 `python server.py admin-token` 取得一次性凭证，再在页面登录。凭证十分钟内有效，审核会话一小时。网页支持书信、附件、画格投稿及举报复核，也可查看操作记录。


在项目目录的终端中查看待审书信和举报。

```powershell
python server.py review
```

复制所列信件 ID，替换下面的 ID。若系统未将 Python 加入 PATH，此电脑可用 `D:\anaconda3\python.exe` 替代 `python`。

```powershell
python server.py review --approve ID
python server.py review --reject ID
```

待审附件可用 `python server.py review --export-media ID 输出文件名` 导出查看。举报复核时，approve 保留原信并结案，reject 将信件撤下。

## 项目结构

- `public/` 存放桌面与移动端页面、样式和交互脚本。
- `public/art/` 存放为本项目绘制的海岸、生活主题及中秋共创插图。
- `server.py` 提供本地 HTTP 服务、账号、内容审核和数据存储。
- `tools/artwork.py` 可重新生成插画，日常运行网页无需执行。
