# 海上有信

面向两岸及海外华人青年的本地数字书信网页。使用 Python 3.10 及以上版本和 SQLite，无需安装第三方依赖。

## 打开项目

在 Windows 上双击「启动项目.cmd」。它会启动书信服务并打开浏览器。已经运行时会打开现有网页。通过终端启动也可以执行以下命令。

```powershell
python server.py --open
```

本机访问地址为 http://127.0.0.1:8765/ 。服务默认只监听本机，关闭运行服务的终端即可停止。书信、账号、授权及附件保存在 data/letters.sqlite3，草稿保存在当前浏览器中。需要长期保留访客书信时，请到「我的海」选择「保存为账号」。

## 体验故事

完整示例库含 40 封书信、21 个公开地域和 24 次跨地接力。作者与故事均为原创虚构示例。进入「拾信广场」查找来信，或从「故事回响」查看分支。用两个不同的浏览器配置或一个普通窗口与一个隐私窗口，可以模拟两个独立参与者。示例作者用于展示，真实的私信往来请使用两个自己的测试身份。

作者寄出的新信会显示在「我的海」。公开来信和公开接力须经本机管理员审核。通过后刷新网页即可在拾信、故事树与时间线中看到更新。私密回信直接存入双方的私人信箱。作者可分别设置接力与展览授权，也可撤回整封信。

## 中秋共创版

首页的书信地球按公开地域显示信封，金色航线表示跨地域的公开接力。拖动或按方向键旋转地球，点选信封可拆信或浏览同一地点的其他来信。地点选择框也能定位到球体背面的区域。陆地点阵来自公有领域的 Natural Earth 1:110m。首页的四个文化空间分别通往乡音录音、画格接力、文化地图和知识图谱。升级会向现有 SQLite 数据库一次性补入示例。全新示例库的六个画格中，四格已有展出，两格留白；已有认领、投稿及撤回记录的画格按原有状态展示。

1. 打开「文化地图」，可从泉州、台北、香港、龙泉、槟城乔治市、越南会安等 12 个地点进入 20 张文化卡，查看资料来源和相关来信。
2. 阅读开放接力的书信。选中一句原文并点击「公开接力」，或在编辑时从原信中选句。写信或接力时，可从 10 张内置封面中选一张，也可上传自己的 JPG、PNG 或 WebP 图片（最大 8 MB，由浏览器压缩）。可再附一张正文图片或一段录音，并从 7 种信纸与 7 枚邮票中搭配。点击「预览信笺」查看组合，点击「保存草稿」可在同一浏览器恢复封面和样式。
3. 打开「共创工坊」，选择空画格并认领。插图与手记可关联本人已公开且授权展出的原信。关联照片会进入在线长卷和 PNG，关联录音可在展览里播放。填写内容并确认展示授权后送审。可以手绘、添加印章、放置文字。作者勾选允许二创且版本公开后，其他身份可以在这一版上继续添加图层，合作记录保留各自的署名。
4. 通过审核后，从页脚进入「中秋主题展」，查看合卷、贡献版本、署名和来源，或导出 PNG。撤回后，展览与再次导出的长卷会更新；已下载到他人设备的文件不会远程更新。

乡音馆收录 32 段附出处与许可的原声。知识图谱收录 35 个文化词条和 33 条不同的文化关系，可从地图进入对应词条或乡音档案。

### 文化标签

默认使用本机词表。点击「识别文化元素」取得候选，点击候选后才加入书信。也可直接输入标签。若要使用模型，站点管理员可以在启动服务前设置这些环境变量。

| 变量 | 含义 |
| --- | --- |
| `SEA_TAG_MODEL_URL` | 完整的 Chat Completions 兼容端点。远端使用 HTTPS，本机回环服务可使用 HTTP。 |
| `SEA_TAG_MODEL_NAME` | 服务所用模型名称。 |
| `SEA_TAG_MODEL_KEY` | 服务要求认证时使用的密钥，保留在服务端。 |

只有作者为本次识别单独勾选授权后，服务才向所配置端点提交标题和正文。界面注明候选来自模型或本地词表。端点未配置或不可用时，仍可手动选词、写信和共创。

## 管理审核

可从网页页脚打开「内容审核」。先在本机项目目录执行 `python server.py admin-token` 取得一次性凭证，再在页面登录。凭证十分钟内有效，审核会话一小时。网页支持书信、附件、画格投稿及举报复核，也可查看操作记录。


在项目目录的终端中查看待审书信和举报。

```powershell
python server.py review
```

复制所列信件 ID，替换下面的 ID。若系统未将 Python 加入 PATH，此电脑可用 `D:\anaconda3\python.exe` 替代 `python`。

```powershell
python server.py review --approve ID
python server.py review --reject ID
```

待审附件可用 `python server.py review --export-media ID 输出文件名` 导出查看。举报复核时，approve 保留原信并结案，reject 将信件撤下。

## 项目结构

- `public/` 存放桌面与移动端页面、样式和交互脚本。
- `public/art/` 存放为本项目绘制的海岸、生活主题及中秋共创插图。
- `server.py` 提供本地 HTTP 服务、账号、内容审核和数据存储。
- `tools/artwork.py` 可重新生成插画，日常运行网页无需执行。
